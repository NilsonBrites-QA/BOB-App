Quantas APIs, por que e para quê?
São 4 APIs no total, cada uma com papel único e fallback definido:
A football-data.org é a principal de dados esportivos — gratuita e permanente para Série A BR. Ela entrega fixtures, standings e resultados. O fallback é a API-Football (100 req/dia grátis) que entra automaticamente se a principal retornar erro 5xx. O orquestrador tenta a principal, aguarda 3 segundos, e se falhar usa o backup — o usuário nunca vê isso, apenas recebe os dados.
A Anthropic Claude API (Sonnet) é o cérebro do BOB — análise, scoring, geração das variações, linguagem natural. O fallback é a OpenAI GPT-4o com o mesmo prompt estruturado. Claude é superior para raciocínio analítico em cadeia, mas GPT-4o é o seguro.
O Supabase não é uma API externa mas um serviço gerenciado — PostgreSQL + Auth + pgvector + storage. O fallback de cache rápido é o Vercel KV (Redis) para sessão e rate limiting.
Login com Google — como limita o acesso?
No Supabase você cria uma tabela allowed_users com os e-mails autorizados. O middleware do Next.js intercepta toda requisição, verifica o JWT, extrai o e-mail e consulta essa tabela. Se o e-mail não estiver lá, redireciona para tela de acesso negado com mensagem clara. Você gerencia a lista direto no dashboard do Supabase — adiciona, remove, sem tocar no código.
OpenAI é a melhor IA? Não para o BOB. Claude Sonnet é melhor em raciocínio estruturado em cadeia longa, que é exatamente o que o sistema cognitivo exige — ele precisa pensar em 10 variáveis ao mesmo tempo, ponderar contradições e gerar justificativa rastreável. O GPT-4o fica como fallback de segurança.
Algoritmo quântico — o que isso significa na prática? No sentido técnico implementável, significa que o BOB não toma decisões binárias. Cada jogo tem um espectro de probabilidade contínuo. A "superposição" é a Matriz de Cobertura das 5 variações: em vez de escolher um resultado, o BOB cobre simultaneamente os estados mais prováveis com custo mínimo. O "colapso" acontece quando o resultado real é registrado e o sistema aprende qual hipótese era a correta, ajustando os pesos internos para a próxima rodada.
Mensagens de erro claras: cada integração tem códigos de erro mapeados com mensagem em português. Rede indisponível → "Estamos sem conexão, tente em instantes." API de futebol sem dados → "Dados da rodada ainda não disponíveis — a análise estará pronta em X horas." Claude indisponível → "Cérebro em manutenção, usando modo alternativo." E-mail não autorizado → "Este e-mail não está na lista beta. Entre em contato com o criador do BOB."
